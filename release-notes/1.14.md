## New
- **Value over time per binder:** the collection value screen has chips at the top, like the stats screen: all cards, Unsorted or one binder. The chart, the total and the rising/falling cards follow the choice. Binder values are saved from this version on, so a binder's chart starts today.

Install `PokeTrader-1.14.apk` (64-bit ARM phones) or `PokeTrader-1.14-universal.apk` (any device).
