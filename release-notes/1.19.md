## Fixed
- **Pictures for 30th Classic Collection:** its 30 cards showed no picture. TCGdex has none for them, and the backup picture source (pokemontcg.io) moved the pictures of sets from 2026 on to a new server. The app now uses that server for those sets.
- Sets that the two sources name slightly differently ("30th Classic Collection" and "30th Celebration: Classic Collection") are now recognised as the same set, when their card counts match.

Install `PokeTrader-1.19.apk` (64-bit ARM phones) or `PokeTrader-1.19-universal.apk` (any device).
