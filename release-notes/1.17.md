## New
- **Download bar for TCGplayer's prices:** like Cardmarket's, a bar above the tabs shows how far the daily TCGplayer download is (cards done of the total), and a note if it failed.
- **Once a day, also after a failure:** if the download fails (for example when you're offline), the app waits a few hours before trying again instead of retrying every time it opens. Settings shows the last download and any error.

Install `PokeTrader-1.17.apk` (64-bit ARM phones) or `PokeTrader-1.17-universal.apk` (any device).
